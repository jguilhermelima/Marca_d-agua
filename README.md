<h1 align="center"> Imagem marca d'agua </h1>

<h2>Descrição do Projeto</h2>
Este aplicativo tem como funcionalidade adionar uma marca d'agua em uma imagem selecionada.

A parte de interface e seleção de um arquivo do computador é feita utilizando tkinter, a inserção de uma marca d'agua é feita utilizando Pillow.

Passo a passo:

* Selecionar imagem salva no computador.

* Selecionar posição da marca d'agua.

* Digitar a marca d'agua que deseja.
  
* Clicar botão inserir marca.
